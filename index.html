What Does EcoPick Do?

EcoPick connects every stakeholder across the plastic recovery lifecycle.

Customer (Seller)  →  Eco Driver  →  Collection Hub  →  Recycling Company

1. Collect

On-demand pickup scheduling from homes, shops, and offices at transparent rates.

2. Transport

Nearby drivers accept jobs, navigate, collect, and transport material safely.

3. Purchase

Verified recycling industries purchase verified plastic batches by grade and quantity.

4. Circular Reuse

Shredded and processed plastic converts back into high-value manufacturing raw materials.

Firebase Configuration

Enter your Firebase project credentials or review Firestore Security Rules.

Paste your Firebase web config JSON below to link live Firebase Authentication, Cloud Firestore & Firebase Storage:

Copy and paste these updated rules into your Firebase Console > Firestore Database > Rules: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Helper function for Admin check
    function isAdmin() {
      return request.auth != null && 
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }

    // Users Collection
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && (request.auth.uid == userId || isAdmin());
    }
    // Pickups Collection
    match /pickups/{pickupId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update: if request.auth != null;
    }
    // Driver Earnings Collection
    match /driverEarnings/{transId} {
      allow read: if request.auth != null && (resource.data.driverId == request.auth.uid || isAdmin());
      allow write: if request.auth != null;
    }
    // Customer Earnings Collection
    match /customerEarnings/{transId} {
      allow read: if request.auth != null && (resource.data.customerId == request.auth.uid || isAdmin());
      allow write: if request.auth != null;
    }
    // Central Plastic Inventory
    match /plasticInventory/{stockId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    // Live Polymer Pricing
    match /pricing/{plasticType} {
      allow read: if true;
      allow write: if isAdmin();
    }
    // Purchases Collection
    match /purchases/{purchaseId} {
      allow read: if request.auth != null && (resource.data.buyerId == request.auth.uid || isAdmin());
      allow create: if request.auth != null;
    }
    // Notifications Collection
    match /notifications/{notifId} {
      allow read: if request.auth != null && (resource.data.userId == request.auth.uid || isAdmin());
      allow write: if request.auth != null;
    }
  }
}
